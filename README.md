# lumina-menu

A React Native digital menu app for restaurants and cafes.

Customers scan a QR code to view the menu on their phone. Business owners can update menu items in real time.

## Tech Stack
- **Mobile:** React Native
- **Backend:** Supabase

## Features
- QR code menu access
- Chinese / English language toggle
- Real-time menu updates by owner
- Clean, mobile-first UI
